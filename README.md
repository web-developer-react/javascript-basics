# JavaScript Basics

Восемь практических заданий модуля 10 Skillfactory. Каждое решение работает отдельно на обычном JavaScript. Установка программ и запуск сервера не нужны.

## Как запустить

1. Открой папку нужного задания.
2. Открой её `index.html` в браузере. Программа запустится сразу.
3. Введи данные во всплывающем окне. Готовый пример уже подставлен.
4. Прочитай ответ в следующем окне. Он также записывается в консоль браузера.
5. Для повторения нажми **ОК**, для завершения — **Отмена**. Чтобы начать заново позже, обнови страницу.

Для просмотра записей открой инструменты разработчика браузера и выбери вкладку **Console**. Если прежних записей нет, оставь консоль открытой и обнови страницу.

## Задания

- [01_parity](01_parity/index.html) — проверка чётности целого числа. Пример: `8` → «Число чётное».
- [02_types](02_types/index.html) — определение типа значения. Пример: `true` → «x — логический тип».
- [03_reverse](03_reverse/index.html) — разворот строки. Пример: `Hello` → `olleH`.
- [04_random](04_random/index.html) — случайное целое число от 0 до 100 включительно. Ввод не нужен.
- [05_iteration](05_iteration/index.html) — количество элементов массива и вывод каждого элемента. Пример: `яблоко, груша, слива` → 3 элемента.
- [06_equality](06_equality/index.html) — сравнение элементов массива. Пример: `кот, кот, кот` → `true`.
- [07_counting](07_counting/index.html) — подсчёт чётных чисел, нечётных чисел и нулей. Пример: `0, 1, 2, 3, 4` → 2 чётных, 2 нечётных и 1 ноль.
- [08_maps](08_maps/index.html) — ввод и вывод пар «ключ — значение» в коллекции `Map`.

## Что находится в файлах

В каждой папке задания ровно два файла:

- `index.html` — страница для запуска. Подключает соседний `main.js` через `<script src="main.js" defer></script>`. Атрибут `defer` откладывает выполнение скрипта до разбора HTML.
- `main.js` — решение задания, ввод данных и вывод ответа. Русские комментарии объясняют важные строки и действия.

В корне проекта:

- `README.md` — эта инструкция.
- `.gitignore` — исключает служебные файлы Finder `.DS_Store` из новых добавлений в Git. Git — система сохранения истории изменений проекта.

В HTML указаны русский язык, кодировка UTF-8, название вкладки и настройка ширины страницы. Тег `head` содержит эти настройки, а `body` оставлен пустым: весь ввод и вывод происходит через окна браузера. CSS, псевдоклассы и псевдоэлементы не используются.

## Как работают окна

- `prompt` — просит ввести данные. Возвращает текст или `null`, если нажата «Отмена».
- `alert` — показывает результат. Вводить данные в него нельзя.
- `confirm` — предлагает выбор. **ОК** означает «да», **Отмена** — «нет».
- `console.log` — сохраняет результат в консоли браузера.

## Как вводить данные

- В заданиях 5–7 разделяй элементы запятыми: `1, 2, 3`. Скобки и кавычки не нужны. Пробелы по краям элементов убираются. Запятая внутри одного элемента не поддерживается.
- В заданиях 5 и 6 элементы остаются текстом. Поэтому `5` и `05` различаются, как и `кот` и `Кот`. Пустой ввод создаёт пустой массив. Для пустого массива и одного элемента сравнение возвращает `true`: отличий не найдено.
- В задании 2 число преобразуется в числовой тип, слова `true` и `false` — в логический тип, `null` — в отсутствие значения. Остальной ввод остаётся строкой. Пиши эти специальные слова строчными буквами и без кавычек.
- В задании 7 числовые записи превращаются в числа. Текст, пустые записи, дроби и бесконечность пропускаются. Нули считаются отдельно. Для заданий 1 и 7 используй обычные небольшие целые числа: очень большие числа JavaScript может хранить неточно.
- В задании 8 вводи ключ и значение в двух отдельных окнах. Они остаются текстом. Повторный ключ заменяет прежнее значение. «Отмена» при вводе заканчивает добавление пар и показывает уже собранную коллекцию.
- В задании 3 используется простой разворот обычного текста. Некоторые эмодзи состоят из нескольких частей и могут развернуться некорректно.
